Deployment Checklist

Verify Your Google Apps Script Deployment:

  1. Go to Google Apps Script
  2. Open your Omni-Vault project
  3. Click "Deploy" → "Manage deployments"
  4. Click the edit icon (pencil) next to your deployment
  5. Ensure these exact settings:
    • Type: Web app
    • Execute as: Me (your email)
    • Who has access: Anyone (or Anyone with Google account)
  6. Click "Deploy" to create a new version
  7. Copy the NEW web app URL
  8. Update it in your script.js file

Common Issues & Solutions

  • Deployment Type: Must be "Web app" (not API executable)
  • Access Level: Must be "Anyone" for external access
  • Execution: Must be "Me (your email)"
  • Version: Ensure you're using the latest deployment URL
