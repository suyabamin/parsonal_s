2 Verify Deployment Settings

These are the most common causes of "Failed to fetch" errors:

  • ✅ Deployment Type: Must be "Web app" (not API executable)
  • ✅ Execute as: Must be "Me (your-email@gmail.com)"
  • ✅ Who has access: Should be "Anyone" for testing
  • ✅ New Version: Make sure you clicked "Deploy" after changes

    • 3 Common Solutions

    If Test Fails:

    • ❌ 404 Error: URL is incorrect or expired - redeploy
    • ❌ CORS Error: Deployment settings wrong - check access level
    • ❌ Authentication Error: "Execute as" setting wrong - must be "Me"
    • ❌ Permission Denied: "Who has access" too restrictive - set to "Anyone"

    4 Quick Fix Process

    1. Go to your Google Apps Script project
    2. Click "Deploy" > "Manage deployments"
    3. Click the edit icon (pencil) on your deployment
    4. Verify all settings match the checklist above
    5. Click "Deploy" to create a new version
    6. Copy the new URL and update it in your script.js file
    7. Test again using the button above
