🔧 Fix Google Drive Connection

Follow these steps to fix the "Drive server disconnected" issue:

1 Verify Google Apps Script Deployment

Most common cause of disconnection is incorrect deployment settings:

  • ✅ Go to script.google.com
  • ✅ Open your Omni-Vault project
  • ✅ Click "Deploy" > "Manage deployments"
  • ✅ Verify these exact settings:
    • Type: Web app
    • Execute as: Me (your email)
    • Who has access: Anyone (or Anyone with Google account)
  • ✅ Click "Deploy" to create a new version
  • ✅ Copy the NEW URL that appears

    • 2 Test Connection with Your Current URL

    Current URL in script.js: https://script.google.com/macros/s/AKfycbzMFT8H6LyjVm3CDs9VR8ON25qfZ1YRO4AnXP5ETopVXMWTPt_5agUKWka-FyGrE8iieQ/exec

    3 Common Issues & Fixes

  • ❌ Deployment Type Wrong: Must be "Web app", not "API executable"
  • ❌ Access Level Too Restricted: Set to "Anyone" for testing
  • ❌ Old Version: Need to redeploy for new version
  • ❌ Missing Functions: Verify testConnection function exists

    • 4 Update Script URL if Needed

    If you get a new URL from redeployment:

    1. Open d:\ps\script.js in a text editor
    2. Find the line: const SCRIPT_URL = '...';
    3. Replace the URL with your new deployment URL
    4. Save the file

    5 Final Verification

    After fixing deployment:

    1. Refresh your index.html page
    2. Check if status shows "Drive Connected"
    3. Try uploading a small test file
    4. Verify file appears in your Google Drive
