🔧 Fix Google Drive Integration

Follow these steps to make files save permanently in Google Drive:

Step 1: Check Google Apps Script Deployment

Go to your Google Apps Script project and verify:

  • ✅ Click "Deploy" > "Manage deployments"
  • ✅ Edit your current deployment
  • ✅ Check these settings:
    • Type: Web app
    • Execute as: Me (your email)
    • Who has access: Anyone (or "Anyone with Google account")
  • ✅ Click "Deploy" to create a new version
  • ✅ Copy the new URL

Step 2: Update Your Script URL

After getting the new URL from Step 1:

  1. Open your script.js file
  2. Find all instances of the old URL
  3. Replace with your new deployment URL
  4. Save the file
// Look for this line in script.js: // const response = await fetch('YOUR_OLD_URL', {...}) // Replace with your new URL

Step 3: Test the Connection

Step 4: Verify File Upload to Drive

After fixing the connection:

  1. Upload a test file (PDF, image, or video)
  2. Check if it shows "Drive" instead of "Local" indicator
  3. Verify the file appears in your Google Drive
  4. Look for folder named "Omni-Vault-Files" in your Drive

Troubleshooting Common Issues:

  • ❌ "Failed to fetch": Deployment settings incorrect
  • ❌ Authentication errors: Check "Execute as" setting
  • ❌ Permission denied: Check "Who has access" setting
  • ❌ 404 errors: URL might be incorrect or expired

Quick Fix Checklist:

  • ☐ Google Apps Script deployed as Web app
  • ☐ "Execute as: Me" selected
  • ☐ "Who has access: Anyone" selected
  • ☐ New deployment URL copied
  • ☐ URL updated in script.js file
  • ☐ Test connection successful
  • ☐ File upload shows "Drive" indicator
